APR 00 - FORMULAS E EXERCICIOS
1. ESTATISTICA
Media: $\mu=\frac{\sum x_i}{N}$
Variancia populacional: $\sigma^2=\frac{\sum(x_i-\mu)^2}{N}$
Desvio padrao: $\sigma=\sqrt{\sigma^2}$
Z-score: $z=\frac{x-\mu}{\sigma}$
Min-max: $x'=\frac{x-x_{\min}}{x_{\max}-x_{\min}}$
EX: x=15, min=5, max=25 => (15-5)/20=0.5.
EX: [2,4,6], media=4, var=(4+0+4)/3=8/3.
2. MATRIZES
Produto A(m,n) B(n,p) => C(m,p).
EX: [1 2] [3;4] => 1*3+2*4=11.
Transposta troca linhas/colunas.
3. DIMENSOES DOS DADOS
X(N,M): N exemplos, M features.
y(N,1): labels. No codigo manual por vezes X(M,N).
Ex: 768 registos, 3 features -> X=(768,3).

5. METRICAS
$AC=\frac{TP+TN}{TP+TN+FP+FN}$
$SE=\frac{TP}{TP+FN}$
$SP=\frac{TN}{TN+FP}$
$PR=\frac{TP}{TP+FP}$
$F1=\frac{2TP}{2TP+FP+FN}$
EX: TP=30 TN=50 FP=10 FN=10:
AC=80/100=.80; SE=30/40=.75; SP=50/60=.833;
PR=30/40=.75; F1=60/80=.75.
